# DESKi (HeartFocus)

> DESKi is a French medical-device software company (Bordeaux, founded 2016) that builds
> AI-guided cardiac ultrasound software under the HeartFocus brand. HeartFocus is an
> FDA-cleared iPhone/iPad app that guides any healthcare professional through the 10
> standard transthoracic echocardiographic views on Butterfly Network iQ+ and iQ3 probes;
> HeartFocus Link brings the same guidance to existing cart-based ultrasound systems over
> HDMI, for education and training only. DESKi publishes **no public API, no OpenAPI or
> AsyncAPI specification, no GraphQL endpoint, no SDK, no CLI, no MCP server and no
> developer portal.** Its only machine-facing integration surface is **DICOM**: the app
> pushes completed exams to a PACS server the customer configures. This file is generated
> by API Evangelist from DESKi's public website and product documentation; it is not
> published by DESKi.

## APIs

- **No public API surface.** `/openapi.json`, `/openapi.yaml`, `/swagger.json`,
  `/v1/openapi.json`, `/api-docs`, `/redoc`, `/graphql` and `/llms.txt` all return HTTP 404
  on both `www.heartfocus.ai` and `deski.ai`. `api.heartfocus.ai`, `developer.heartfocus.ai`
  and `link.heartfocus.ai` do not resolve in DNS. `docs.heartfocus.ai` resolves to an S3
  bucket that returns HTTP 403 AccessDenied. Every `/.well-known/*` path returns 404
  ("Invalid .well-known request"). Checked 2026-08-17.
- `portal.heartfocus.ai` is a customer licence-management application, not a developer
  surface. It is a single-page app whose catch-all answers HTTP 200 with the same 467-byte
  HTML shell for every path, including `/openapi.json` and `/.well-known/agent-card.json` —
  those are not documents.

## Integration surface (DICOM, not HTTP)

- **DICOM Storage SCU.** HeartFocus transfers validated exams to a customer-operated PACS.
  The in-app DICOM server form takes: server application entity title, client application
  entity title, server IP or hostname, server port, and an optional TLS toggle. A "Test"
  action verifies the connection. Transfers are recorded in the app's audit log.
- **DICOM conformance statement**: exists but is **not published** — available only by
  emailing `support@deski.ai`. This is the document an integrator needs (SOP classes,
  transfer syntaxes, AE roles), and it is the DICOM equivalent of an OpenAPI.
- **SBOM**: a machine-readable CycloneDX (CDX) SBOM is offered, also only by email to
  `support@deski.ai`.
- **No idempotency.** Documented explicitly: resending the same exam produces a new ID, so
  the exam is duplicated on the PACS rather than overwritten. Reconciliation is the user's
  responsibility.
- **Butterfly Cloud export**: Butterfly Enterprise customers can export HeartFocus exams
  via Butterfly Link, arranged with Butterfly rather than DESKi.
- Internet is required only to install/update the app, verify the licence every 30 days,
  and send exams to a PACS. Scanning and AI guidance run fully offline.

## Products

- [HeartFocus](https://www.heartfocus.ai/product): FDA-cleared AI cardiac imaging app for
  iPhone and iPad with Butterfly iQ+ and iQ3 probes. Live probe guidance, Auto-Record when
  diagnostic quality is held for ~2.2s, Best-Effort-Record fallback, Manual Record, live
  view-quality percentage, DICOM send to PACS. 10 views: PLAX, PSAX-AV, PSAX-MV, PSAX-PM,
  A4C, A5C, A2C, A3C, SC-4C, SC-IVC.
- [HeartFocus Link](https://www.heartfocus.ai/heartfocus-link): iPad app that captures the
  video output of an existing cart-based ultrasound system over HDMI (plus a USB 3.0 video
  capture card and an iPad adapter) and overlays the same AI guidance. Fully local
  processing, no cloud, no network. **Education, training and image-acquisition practice
  only — not for diagnostic use, clinical decision-making or treatment guidance.** Stated
  compatible in principle with any cart system that has HDMI/DisplayPort output; GE
  HealthCare, Philips, Siemens Healthineers, Mindray, FUJIFILM Sonosite, Samsung and Canon
  are named. Available in France and the United States. No FDA or CE submission planned.
- [POCUS HeartFocus Certification](https://www.heartfocus.ai/pocus-heartfocus-certification):
  competency validation for cardiac ultrasound image acquisition with HeartFocus.
- HeartFocus Education: **retired 2025-08-24.** Was free, distributed via Butterfly Garden,
  education only, not a medical device.

## Regulatory and security

- **FDA 510(k) K242807** — HeartFocus (V.1.1.1), Traditional, decided 2025-04-04, product
  code QJU, Radiology panel.
- **FDA 510(k) K260780** — HeartFocus, Special, decided 2026-06-03, product code QJU.
- [HIPAA & HBNR Applicability Statement](https://www.heartfocus.ai/hipaa-hbnr-applicability-statement)
  (2025-08-20): DESKi asserts HeartFocus is **not subject to HIPAA** because it does not
  create, receive, maintain or transmit PHI on behalf of any healthcare entity and does not
  access or store patient data. Note that the marketing pages separately claim
  "HIPAA-compliant workflows"; both are DESKi's own published statements.
- [Coordinated Vulnerability Disclosure](https://www.heartfocus.ai/security/cvd):
  reports to `security@deski.ai`, PGP encryption requested, acknowledgement within two
  business days. No bug bounty. No `/.well-known/security.txt` — but the `heartfocus.ai`
  CAA record carries `0 iodef "mailto:security@deski.ai"`.
- Scans are stored locally on the device; DESKi states no data is sent to DESKi servers.
  TLS on the DICOM link is recommended but customer-toggleable.
- Domain posture (probed 2026-08-17): TLSv1.3, HSTS max-age 31536000, SPF present, DMARC
  present with `p=none`, CAA present, **DNSSEC not enabled**.
- No SOC 2, ISO 27001, ISO 13485 or CE/MDR claim was found on any public page. No trust
  center exists.

## For providers

DESKi could become machine-readable without shipping a new product. The three highest-value
moves, in order: publish the **DICOM conformance statement** at a stable URL instead of by
email request; publish the **CycloneDX SBOM** at a URL so it can be fetched and diffed; and
serve **`/.well-known/security.txt`** pointing at the existing CVD policy, which already
exists and is already referenced in DNS via CAA `iodef`. Corrections and re-scores are free:
info@apievangelist.com.
